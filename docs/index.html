What each file keeps

      

        

          
Solido image

          
The blueprint a Solido Replicator stores, in the shape used by a live-base export: pieces and placeables relative to the claim console, plus the base name, map, and origin.

          
    
            
  • Building pieces, with yaw
    • 
            
  • Placeables, with pitch, yaw, and roll
    • 
            
  • Where the console stood
    • 
          

        

        

          
Base backup

          
The dune-base-backup file a Base Reconstruction Tool import expects. It carries the whole placed base, not a hologram.

          
    
            
  • The same pieces and placeables, in world coordinates
    • 
            
  • A claim console, building actor, and empty containers
    • 
            
  • Items, permissions, fuel, water, and staking tiles when they were already in the backup
    • 
          

        

      

      
A solido never contained the chests. Converting one into a backup rebuilds the rooms and machines empty, unless you check Fill water cisterns. That writes each cistern to its in-game capacity. Converting a backup into a solido leaves stored water and items behind on purpose, so the file can be imported as a blueprint. Pentashield facing is kept. Shield size and staking tiles are not part of a live solido image.
